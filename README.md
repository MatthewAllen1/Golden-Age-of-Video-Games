# Video Game Industry Analysis | PostgreSQL & Python

An exploratory analysis of historical video game sales and review datasets, originally completed for data analytics coursework.

## Contents
- `datasets/` — CSV and SQL assets
- `notebook.ipynb` — analysis notebook

## Reproduce
Load the included CSV/SQL assets into an isolated PostgreSQL database, then inspect the notebook. Verify the database connection parameters in your local environment before running it; no access to external services is provided here.

## Skills
Data exploration, SQL querying, joining tables, notebook-based analysis and communicating observations. Original dataset provenance should be verified before redistribution or additional use.
